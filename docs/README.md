# Документация chestor-bot.site

Сайт бота CheStor ([`SelfTopic/chestor_bot`](https://github.com/SelfTopic/chestor_bot)):
лендинг, справка для игроков, позже — живые данные игры и Telegram Mini App.

Правила для кода — в [`../CLAUDE.md`](../CLAUDE.md). Здесь:

- [`spec.md`](spec.md) — техническое задание: зачем сайт, для кого, этапы и требования.
- [`stack.md`](stack.md) — язык, стек, хостинг и деплой, связь с ботом.
- [`brand.md`](brand.md) — образ: маскот CheStor, его характер, внешность, состояния.

## Как читать

Документы живые, как `docs/design/` бота: решения дописываются по мере обсуждения.

- ✅ **решено** — договорились, можно делать.
- 🔲 **открыто** — нужно решение владельца, без него не начинать.
- 💡 **идея** — можно сделать, решить, нужно ли вообще.

Пункт с пометкой «предложение» — вариант, который предложен, но владельцем ещё не
подтверждён: до подтверждения это 🔲.
